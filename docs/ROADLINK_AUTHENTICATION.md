# 认证配置

CarPlay 的软件通信与配件认证是两个必要部分。USB/Wi-Fi 连通不能替代认证。

## 本地文件

在启动页分别选择已有 `identity.pk8` 与 `certificate.p7b`，点击“校验并安装所选文件”。只通过系统选择器读取所选文档，不使用全盘存储权限。

- 每个文件最多 16 KiB；空、过大、读取失败、错误格式和不匹配的材料均拒绝。
- 加载器要求 PKCS#8 EC P-256 私钥和匹配的证书，具体接受格式由现有加载器决定。
- 签名匹配只证明私钥和公钥一致，不证明 Apple 签发、用途授权或 iPhone 接受。
- 文件保存在应用 `noBackupFilesDir`，不进入诊断和公开仓库，不自动上传。
- 失败不替换已有有效配置；目录提交中断有恢复路径；活动会话期间不可修改。
- 导入工作由 ViewModel 保留，旋转屏幕不依赖旧 Activity 存活。

本项目不会签发或提供实际身份。请只使用自己有权使用的材料，不把材料发到 Issue、GitHub、测试夹具或日志中。

## USB/CH341

需要 CH341 桥接到兼容认证协处理器，单独的 CH341 转接器不足。仍需实物确认 VID/PID、接线、供电、USB 权限与内核兼容性。本分支没有对任何实物模块进行验证。

## 分发

普通源码/CI APK 不含身份，用户在自己的应用私有目录配置。上游保留的显式构建时认证入口是另一路线，使用它会让材料可从 APK 提取，不属于本分支公开开发包的默认方式。

实际身份与 Android 签名私钥必须保留在 Git 之外。移除文件不代表完成闪存上的物理安全擦除。
